# DMD — сайти Яни Мишковської

Чотири односторінкові сайти, зверстані з Figma (Yana Myshkovska DMD). Кожен лежить у своїй папці і публікується на Vercel як окремий проєкт (Root Directory = назва папки).

- `tideline/` — TIDELINE, серф-школа (I), сайт з машиною
- `first-motion/` — TIDELINE, FIRST MOTION (III)
- `form/` — FØRM, догляд за шкірою
- `unbound/` — UN//BOUND, фестиваль електронної музики

Статичні сайти: HTML, CSS, JavaScript, без збирання.
